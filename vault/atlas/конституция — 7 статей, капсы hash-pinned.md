# Конституция — 7 статей, капсы hash-pinned

Источник истины — `CONSTITUTION.md` в корне репозитория (вне vault: его читает рантайм, `ops/caps_guard.py` сверяет sha256 капсов при каждом старте демона). Эта заметка — карта для графа.

1. **Единственная правда** — биржа; журнал — кеш (v1 наврал в 40x). Reconcile с первой сделки, `clientOrderId` в каждом ордере, полный промпт+ответ в analysis_log
2. **Граница детерминизма** — LLM выбирает из меню опций по id; числа в биржу пишет только Python
3. **Запрет самоусиления** — никакой portfolio-статистики в торговых промптах (петля «14/15 SHORT»); манифест статистик `STATS_MANIFEST.md`; confidence cap 75 на уровне схемы
4. **Процедура капсов** — `config/caps.yaml` hash-pinned; поправка = 60 сделок PF>=1.3 + proposal + 48ч охлаждение + двухшаговый confirm; флага принудительной торговли не существует
5. **Дисциплина валидации** — machine-checkable инвариант ДО деплоя; `committed_not_live_validated` снимает только зеленый прогон; максимум 2 невалидированных изменения подряд
6. **Emergency Stop** — panic немедленно и безусловно; после panic /resume отказывает — только ручной сброс оператором
7. **Vault-дисциплина** — коммит в src/ или config/ без changelog отклоняется хуком; имя заметки = вывод; book_claim до валидации данными
