# Критик — сначала наблюдатель без права вето, судят counterfactual-когорты

## Решение (сессия с Иваном, 2026-08-26)

Иерархия «вторых мнений» по эффективности на токен:

1. **Вето Trader'а — внедряется сразу** (Фаза 2). TradeDecision v2 получает `verdict: execute | decline` с обязательной причиной отказа. Ноль дополнительных вызовов: Trader и так вызывается, но роль другая — Scout мотивирован найти (охотник), Trader — не потерять на исполнении. Редкое вето исполнителя — самое ценное («вход кривой: до ликвидности полшага, стоп в толпе»).
2. **LLM-критик — только в log-only режиме**: оценивает каждый сетап, вердикт пишется в журнал, ни на что НЕ влияет. Через ~100 сетапов сравнение когорт («критик зарубил бы» vs «одобрил» по PF) решает, давать ли право вето. Ст. 5: ничего без machine-checkable валидации.
3. **Полноценные параллельные дебаты (N вызовов на сетап) — отклонено** при подписочной экономике: сжатые дебаты уже в схеме ScoutReport (bull_case / bear_case / bear_rebuttal обязательны, слабый rebuttal = вето риск-движка).

## Против чего решили

Слепой критик на слабой модели (Qwen) с правом вето: слабая модель критикует сильную шумовыми возражениями, подходящими к любому сетапу. Либо игнорируем (бесполезен), либо слушаемся (случайно режет поток, а каждый сетап дорог для статистики гейтов). Асимметричные пары моделей в дебатах дают мало (опыт TradingAgents — дебаты работают между сопоставимыми).

## Правила для любого критика (ст. 3)

- НЕ видит направление портфеля и прошлые вердикты (петля «14/15 SHORT» v1)
- Слепой вариант НЕ видит вердикт Scout'а (иначе якорение)
- Главные «критики» системы бесплатны и уже стоят: риск-лестница, confluence-гейт, cap confidence, counterfactual-датасет. LLM-критик — гипотеза, которую мерят, а не внедряют на веру.
