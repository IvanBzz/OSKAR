## Вопрос

Иван: «куда пойдёт цена — сетап отвечает; сложнее — как додержать сделку до прихода в зону, не уйдя
в ликвидацию». Направление на крипте предсказывается плохо (ночной обзор, литература), волатильность —
хорошо. Значит, полезная цель модели — не цена, а **MAE**: максимальный ход против позиции за время
удержания. Если P95 MAE предсказуем лучше тривиального «ATR × k», можно выбирать плечо/запас маржи, при
котором сделку додерживают в 95% случаев.

## Выборки

- **S0 «каждый бар» (базовая, на ней учимся)**: каждый 4h-бар t каждого символа после прогрева
  (≥ 200 баров истории символа, ATR и все признаки определены) и с полными H барами вперёд,
  **оба направления** d = +1 (лонг) и −1 (шорт) → две строки на бар. Это объявленная базовая выборка:
  сигналов сетапа слишком мало для обучения.
- **S1 «бар с гэп-целью»**: подмножество S0, где в сторону d есть живой гэп 1d/1w в коридоре
  1.5–8 ATR (как в setup_study: `best` конечен). Естественная популяция сетапа; направление — к гэпу.
- **S2 «сигналы»**: бары признаков (b) CHoCH и (d) доджи+CHoCH на 4h с гэп-целью 1d/1w
  (ячейки setup_study `4h/DW/b` и `4h/DW/d`, ~2.3 тыс. и ~0.15 тыс. событий). Только проверка:
  модель, обученная на S0, применяется к сигнальным барам того же тестового года.

## Таргет

Вход по close бара t, направление d, горизонт H ∈ {42, 180} баров 4h (≈ 7 и 30 дней).
**MAE_H = max(0, max_{k=1..H} d·(close_t − P_{t+k}) / ATR14_4h(t))**, где P = low для лонга, high для
шорта. Единицы — ATR сигнального бара (как стопы в OSKAR и setup_study).
Вторичный таргет на S1: **MAE_до_цели** — тот же максимум, но только до бара первого касания
ближней границы гэпа включительно (или до H, если касания нет): именно столько нужно «пересидеть»,
чтобы дождаться прихода в зону.
Для перевода в проценты и плечо используется `atr_pct = ATR/close·100` того же бара.

## Признаки на момент t (только прошлое; последний закрытый бар каждого ТФ на момент close_t)

| Признак | Определение |
|---|---|
| d | направление ±1 |
| atr_pct_4h | ATR14(4h)/close·100 |
| atr_pct_1d | ATR14 последнего закрытого 1d-бара / close·100 |
| rv_1d, rv_3d, rv_7d | σ лог-доходностей 4h за 6/18/42 баров, % |
| rv_ratio | rv_1d / rv_7d (смена режима) |
| range_H_atr | (max high − min low за последние H баров)/ATR — «прошлый аналог» таргета, свой для каждого H |
| pos20_d, pos50_d | положение close в диапазоне 20/50 баров, ориентированное: лонг (close−min)/(max−min), шорт (max−close)/(max−min); 0 = у «своего» края |
| trend_1d_d | d·(close − EMA20 закрытий 1d)/ATR_1d |
| trend_1w_d | d·(close − EMA10 закрытий 1w)/ATR_1w |
| gap_dist_atr | расстояние в ATR до ближайшего живого гэпа 1d/1w в сторону d (`many`); нет гэпа → NaN |
| gap_corr | 1, если гэп в коридоре 1.5–8 ATR |
| gap_size_atr | размер гэпа-цели в коридоре, ATR; NaN если нет |
| gap_tf | 0 нет / 1 = 1d / 2 = 1w |
| dow, hour | день недели и час UTC открытия бара |
| fund_last_d | d·последняя ставка фандинга до close_t, % (положительно = позиция платит) |
| fund_3d_d | d·средняя ставка за последние 9 начислений, % |
| btc_atr_pct, btc_rv_7d | те же волатильности BTC на тот же бар (рынок) |
| log_age | log1p(дней с первого бара символа) |

## Модели (на каждый H и каждый квантиль q ∈ {0.80, 0.95})

- **B0 «ATR × k»**: q̂ = константа = эмпирический q-квантиль таргета на обучении. Таргет уже в ATR,
  поэтому это и есть «ATR × sqrt(H) × k» с k, откалиброванным на обучении; отдельно смотрю, держится ли
  sqrt(H)-масштаб между H = 42 и 180 (k_180/k_42 против sqrt(180/42) = 2.07).
- **B1 HAR-RV**: OLS на обучении log RV_fwd_H = a + b1·log rv_1d + b2·log rv_3d + b3·log rv_7d, где
  RV_fwd_H — σ лог-доходностей следующих H баров. Прогноз 1σ-хода горизонта в ATR:
  s = exp(fit)·sqrt(H)·close/ATR; q̂ = k_q·s, k_q — q-квантиль отношения таргет/s на обучении.
- **M1 линейная квантильная регрессия**: sklearn `QuantileRegressor(alpha=0, solver="highs")` на
  стандартизованных признаках (NaN → медиана обучения + флаг), обучение на случайной подвыборке
  ≤ 40 тыс. строк обучения (ограничение времени LP-решателя — объявлено).
- **M2 градиентный бустинг квантилей**: `HistGradientBoostingRegressor(loss="quantile", quantile=q,
  max_iter=400, learning_rate=0.05, max_leaf_nodes=15, min_samples_leaf=300, l2_regularization=1.0)`,
  NaN обрабатывает сам. Гиперпараметры фиксированы заранее, не подбираются.

## Валидация

Walk-forward по календарному году бара t: тестовые годы Y = 2021 … 2026 (2026 — до октября).
Обучение — все строки, у которых окно таргета целиком закончилось до 1 января Y (purge H баров:
окна обучения не заходят в тестовый год). Внутри года модель не переобучается. Один прогон,
seed фиксирован (подвыборка M1).

## Метрики (на каждый H, q, модель, год + сводно по всем тестовым годам)

- **покрытие** = доля строк с MAE ≤ q̂ (цель ≈ q);
- **pinball loss** ρ_q, средний; **отношение** к B0 (< 1 — лучше базы);
- средний q̂ (резкость при том же покрытии).
То же на S2 (сигналы) и для вторичного таргета на S1.

## Перевод в плечо (на тестовых строках, модель того же года)

Дистанция до ликвидации при изолированной марже ≈ 1/L − MMR (MMR = 0.5 %, первый тир крупных
перпов; приближение, объявлено). Нужный запас: `need = q̂95·atr_pct/100 + 0.001 (две taker-ноги
0.05 %) + fund_H`, где fund_H — P95 накопленного фандинга, уплаченного позицией за H, по обучению
(константа на H и d). Плечо модели **L = floor(1/(need + MMR))**, не выше 20.
Отчёт: медиана и P10 L по годам для B0 и M2; **фактическая выживаемость** (доля строк, где реальный
MAE·atr_pct/100 + 0.001 + реальный фандинг < 1/L − MMR) — должна быть ≈ 95 %; и выживаемость при
фиксированных плечах 1/2/3/5/10× для H = 42 и 180 — прямой ответ «какое плечо додержать».

## Побочный тест: предсказуемо ли направление

Там же, те же признаки: `HistGradientBoostingClassifier` (300 итераций) предсказывает
sign(close_{t+H} − close_t) (только строки d = +1), walk-forward по годам. Метрики: accuracy и AUC
против 0.5 и против доли «вверх» в тестовом году. Заранее: AUC < 0.55 в большинстве лет = направление
этими признаками не предсказывается (ожидание из ночного обзора).

## Критерии успеха (объявлены до расчёта)

1. **Калибровка**: покрытие P95 у M2 в [0.93; 0.97] в ≥ 4 из 6 тестовых лет (P80 — в [0.77; 0.83]).
   Иначе модель не калибрована и для плеча непригодна без поправки.
2. **Лучше базы стабильно**: pinball(M2)/pinball(B0) ≤ 0.95 в ≥ 4 из 6 лет для q = 0.95 и обоих H.
   Только сводно ≤ 0.95 без стабильности по годам — «нестабильно»; ≥ 0.95 — «не лучше базы».
3. **Откуда выигрыш**: тот же тест для B1 (HAR-RV). Если B1 ≈ M2 — выигрыш даёт прогноз волатильности,
   признаки сетапа (гэп, положение, тренд) не добавляют.
4. **Перенос на сигналы**: покрытие P95 модели на S2 в [0.90; 0.98]; ниже 0.90 — сигнальные бары
   рискованнее, чем модель думает (отдельно отметить).
5. Плечо: выживаемость при плече модели в 93–97 % по годам; таблица фиксированных плеч.
