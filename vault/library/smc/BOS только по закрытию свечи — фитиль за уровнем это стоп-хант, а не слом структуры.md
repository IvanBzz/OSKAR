# BOS только по закрытию свечи — фитиль за уровнем это стоп-хант, а не слом структуры

BOS (Break of Structure, слом структуры) подтверждается ТОЛЬКО закрытием свечи за структурным свингом: в аптренде — закрытие выше последнего HH, в даунтренде — закрытие ниже последнего LL. Для самопроверки книга рекомендует линейный график (line chart строится по закрытиям): если на линейном графике пробоя нет — слома нет.

SH (Stop Hunt, стоп-хант, снятие ликвидности, ложный пробой): цена фитилем заходит за предыдущий хай/лой без закрытия за ним. Это НЕ слом структуры — это забор ликвидности (стоп-приказов и стоп-заявок пробойных трейдеров) перед движением в противоположную сторону. Классификация детектором пробоя без проверки закрытия даст ложные BOS на каждом свипе.

Свинг и структура:
- Свинг-хай/лой определяется по правилу 3 свечей: центральная свеча с более низкими соседями (для хая). Judas Swing — агрессивный свип значимой ликвидности (хай/лой сессии, дня, недели) длиннофитильной свечой; может нарушать правило 3 свечей, но остается структурным свингом.
- POB (Point of Breakout) — точка, из которой произошел слом. Пока POB не нарушен, новая структура валидна; тест POB дает сильную реакцию.
- Сильные хаи/лои формируются после импульсного ухода из POI — их цена не может пробить без предварительного BOS против них; тест дает реакцию. Слабые хаи/лои (образованы медленной коррекцией) будут пробиты — за ними лежит ликвидность, они цель, а не защита.
- В сложной коррекции есть под-структура: инвалидация сценария коррекции = BOS выше предыдущего LH (для лонга) / ниже HL (для шорта) внутри коррекционной структуры.

Правило для Scout при чтении детектора bos_choch: сигнал BOS принимать только если close свечи за уровнем; выход за уровень только фитилем перемаркировать как liquidity sweep / stop hunt — это триггер противоположного сценария, а не продолжения.
