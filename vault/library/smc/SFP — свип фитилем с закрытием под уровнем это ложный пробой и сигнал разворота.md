# SFP — свип фитилем с закрытием под уровнем это ложный пробой и сигнал разворота

SFP (Swing Failure Pattern) — свечной паттерн ложного пробоя (false breakout, ложный вынос) экстремума, за которым лежит ликвидность. Ключевое правило подтверждения: свеча, снявшая ликвидность, должна ЗАКРЫТЬСЯ ниже хая свечи, сформировавшей свинг (для медвежьего SFP) / выше лоя свинг-свечи (для бычьего). Пробой происходит только фитилем; тело закрывается обратно под/над уровнем. Работает на всех таймфреймах.

Вход по SFP:
- Консервативный: вход после закрытия SFP-свечи, стоп за ее экстремум.
- Агрессивный: вход на пике SFP от заранее размеченного POI (OB, supply/demand зона старшего ТФ) — до закрытия свечи; риск — свеча может закрыться пробоем.

Родственный инструмент — SC (Sponsored Candle, спонсированная свеча): свеча-манипуляция с длинным фитилем, превышающим тело, которая агрессивно снимает ликвидность; в сочетании со сломом структуры на повышенном объеме — след умных денег. Правила работы с фитилем:
- Длинный фитиль, инициировавший свип, тяготеет к тесту своей середины: уровень 0.5 фитиля (wick 0.5) — зона реакции.
- На LTF 50% высоты фитиля может очерчивать локальную supply/demand зону — будущий POI.
- Идеальный тест SC — 0.5 тела; часто цена сначала тестирует фитиль, затем тело. Возможен вторичный тест тела, если митигация не завершена с первого касания.
- Консервативный стоп — за весь фитиль.

Отличие от истинного пробоя: закрытие свечи ЗА уровнем (подтвержденное на line chart) = BOS, пробой истинный, разворотный сценарий отменен. Дополнительный ранний маркер истинности разворота после SFP — слом локальной структуры LTF в сторону разворота.

Для Scout: событие свипа от детектора liquidity классифицировать по закрытию свечи: close вернулся за уровень = SFP/ложный пробой (разворотный триггер), close за уровнем = пробой (продолжение). SFP на значимом пуле (EQH/EQL, хай/лой дня) + POI старшего ТФ = торгуемый сигнал.
