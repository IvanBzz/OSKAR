# Покупки только в дискаунте, продажи только в премиуме — ключевой уровень OTE 0.705

Главное правило открытия позиций: новые сделки только после коррекции цены в правильную половину диапазона. Покупки — в дискаунте (discount, ниже 0.5), продажи — в премиуме (premium, выше 0.5). Вход по лонгу в премиуме = покупка по завышенной цене против логики умных денег.

Построение сетки Фибоначчи:
- Ретрейсмент натягивается на импульс: 1 в начале импульса, 0 в его конце. Уровень 0.5 = equilibrium (равновесие, справедливая цена).
- OTE (Optimal Trade Entry, оптимальная зона входа): 0.62, 0.705, 0.79. Ключевой разворотный уровень — 0.705.
- SMC-трейдеры не работают от 0.236/0.382: цена должна уйти хотя бы за equilibrium. Прикосновение к 0.5 уже означает возможный набор позиции умными деньгами — при сильном тренде глубокой коррекции в OTE может не быть, но и гарантий отработки OTE нет: приоритет POI (order block, FVG, DP) внутри дискаунт/премиум зоны.

Диапазон (range) для разметки premium/discount:
- Границы: конечный свинг импульса + противоположный экстремум; проверка корректности разметки — реакция цены от уровня 0.5 диапазона.
- Правила работают фрактально: dealing range старшего ТФ задает премиум/дискаунт для свинг-позиций, локальный диапазон — для интрадей.
- Деривативы: хай/лой предыдущего дня (PDH/PDL), недели, открытие дня/недели/месяца (DO/WO/MO) — те же опорные уровни ликвидности для определения дорого/дешево внутри дня.

Применение в связке: полный разворотный сетап требует, чтобы РАЗВОРОТНАЯ зона (OB/FVG/DP) находилась в премиуме (для шорта) или дискаунте (для лонга) диапазона, а вспомогательными факторами были имбаланс выше/ниже зоны интереса, ликвидность за экстремумом и OTE-совпадение.

Для Scout: перед одобрением любого детекторного сетапа проверять положение зоны входа относительно 0.5 текущего dealing range; сетап против правила премиум/дискаунт отклонять или помечать как контртрендовый с пониженным приоритетом.
