# Старший ТФ дает контекст и POI, младший ТФ дает точку входа

Рабочий процесс мультитаймфрейм-анализа (top-down):

1. Анализ всегда сверху вниз: старшие ТФ определяют тренд, структуру и зоны интереса (POI: order block, supply/demand, DP, FVG); младшие ТФ дают подтверждение и точку входа (ТВХ).
2. Свинг-трейдинг: анализ и POI на D1, вход на H4-H1. Интрадей: анализ и POI на H4-H1, вход на M15-M1. Интрадей дополнительно требует учета торговых сессий и OTT (optimal trade time, killzones).
3. Закон иерархии: HTF структура > LTF структура. Пока структура старшего ТФ не сломана, движения младшего — коррекции внутри нее.
4. Синхрон таймфреймов: идеальная сделка — в точке, где направление совпадает на всех рабочих ТФ (точка синхрона), либо в точке разворота, где младшие ТФ последовательно ломаются в сторону сценария старшего (LTF BOS -> HTF SMS -> HTF BOS). 80% сделок торгуется по тренду старшего ТФ, максимум 20% — против тренда и только с подтверждением.
5. Правило поведения перед POI: хочу видеть слабый тренд/компрессию НА ПОДХОДЕ к зоне (обессиленное движение — зона удержится) и НЕ хочу видеть здоровый тренд с планомерной работой с ликвидностью (зона, скорее всего, будет поглощена). Объемы при коррекции к POI должны падать; импульсный подход к зоне на объеме — риск пробоя.
6. Фрактальность: все правила (структура, ликвидность, зоны, диапазоны) действуют одинаково на любом ТФ; сетап старшего ТФ раскладывается в такой же сетап младшего внутри его POI.

Проверка перед входом (сокращенный синхрон-чек): тренд HTF -> цена в премиум/дискаунт HTF-диапазона -> свежий POI HTF -> ожидание LTF слома структуры внутри POI -> вход по LTF-сетапу.

Для Scout: контекст берется из детекторов старшего ТФ (swings, bos_choch, ob, fvg), триггер — из младшего; сигнал младшего ТФ против непроломанной структуры старшего = контртренд, требующий полного набора подтверждений или отклонения.
