# Брейкер-блок — сломанный OB, тест после свипа, вход только с конфлюэнсом

Breaker block (BB, брейкер, сломанный ордер-блок) — order block, который был пробит импульсом ПОСЛЕ снятия ликвидности. Секвенция формирования: OB дает реакцию -> цена свипает ликвидность за противоположным экстремумом -> возвращается и импульсно ПРОБИВАЕТ тело OB (слом структуры). Пробитый OB меняет полярность: бывший bullish OB становится сопротивлением, бывший bearish OB — поддержкой. Поведенческий аналог классического ретеста пробитого уровня (support becomes resistance).

Правила работы:
- Валиден брейкер, пробитый ЧИСТЫМ импульсом (одна-две свечи, малые фитили) после явного свипа ликвидности — это сигнал смены намерения (смены характера рынка).
- В отличие от OB, у брейкера учитывается ВСЯ свеча, включая фитили. Идеальная зона реакции — 0.5 тела.
- Реакция от брейкера слабее, чем от свежего OB: книга прямо запрещает открывать позицию от брейкера БЕЗ сильного конфлюэнса. Брейкер используется как: магнит/промежуточная цель, зона частичной фиксации, фильтр направления.
- Достаточный конфлюэнс для входа от брейкера: формирование FVG/имбаланса в зоне брейкера при сломе (в технике SMR названо важнейшим подтверждением сетапа; вход от ближайшей границы FVG, стоп за разворотный свинг), совпадение с премиум/дискаунт, ликвидность за экстремумом, killzone-время.
- Инвалидация: закрытие цены за дальней границей брейкера (включая фитиль).

Отличие от митигации OB: OB тестируется по направлению своей исходной полярности (demand тестируют сверху для лонга); брейкер тестируется после смены полярности — с обратной стороны, по направлению нового тренда.

Для Scout: детекторный OB, чье тело пробито закрытием после свипа, перемаркировать в breaker: не самостоятельный вход, а зона ретеста для сетапа продолжения нового направления при наличии FVG-подтверждения.
