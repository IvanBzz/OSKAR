# Уменьшение разброса результатов равноценно росту прибыли

Рост счёта при реинвестировании определяется средним геометрическим HPR, а не арифметическим. Оценочная связь (фундаментальное уравнение торговли Винса):

TWR ≈ (A^2 − SD^2)^(N/2), то есть G^2 ≈ A^2 − SD^2,

где A — среднее арифметическое HPR, SD — стандартное отклонение HPR, N — число сделок. Это теорема Пифагора: A — гипотенуза, G — катет, SD — второй катет. Следствие: снижение дисперсии (variance drag, разброс результатов) повышает G ровно так же, как рост средней прибыли. Погоня за TWR = HPR^N по среднему арифметическому — ошибка; при SD > 0 реальный рост всегда ниже.

Почему винрейт с умеренным payoff бьёт редкие большие выигрыши (пример книги):
- Система A: winrate 10%, payoff 28:1, MO = 1,9 на ставку → optimal f = 0,0678, G = 1,0442.
- Система B: winrate 70%, payoff 1,9:1, MO = 0,4 → optimal f = 0,4, G = 1,0858.
Матожидание A в 4,75 раза больше, но B растит счёт почти вдвое быстрее за ставку — из-за меньшего разброса. Восстановление после 50% просадки (нужно +100%): системе A — ~16,5 сделок, системе B — ~9.

Следствия из уравнения:
1. Если A ≤ 1 (матожидание ≤ 0), никакие SD и N не спасут: при N → бесконечность результат → 0, разорение — вопрос времени.
2. Если A > 1, каждая сделка умножает счёт на G — рост N (больше сделок, диверсификация) ускоряет достижение цели.
3. Быстро режь убытки (короткий stop-loss): это уменьшает SD сильнее, чем A. Но слишком тесный стоп вреден — множество мелких стопов по сделкам, которые дошли бы до профита, режет A сильнее, чем SD. Оценивай каждое правило системы (стоп, тейк, фильтр) по критерию: уменьшает ли оно SD больше, чем A.
4. Крупная убыточная сделка бьёт по TWR мультипликативно — одна сделка с HPR около 0 уничтожает произведение.

Для агента: при выборе между сетапами/конфигурациями сравнивай G (или A и SD пару), а не средний профит и не винрейт по отдельности; стабильность результатов — самостоятельный источник доходности.
