# Оптимальное f — делитель наибольшего убытка, а не процент счёта

Формулы Келли (Kelly criterion) для двух исходов (распределение Бернулли):
- Равные выигрыш/проигрыш: f = P − Q = 2P − 1 (P — вероятность выигрыша).
- Фиксированный payoff B: f = ((B + 1) * P − 1) / B. Пример: B = 2, P = 0,5 → f = (3*0,5 − 1)/2 = 0,25.

Ограничение: формулы Келли корректны ТОЛЬКО при постоянных размерах выигрышей и проигрышей. Подставлять средний выигрыш/убыток реальной торговли в Келли — ошибка: в примере книги это даёт f = 0,16 при истинном оптимуме 0,24, что режет доходность втрое на дистанции 900 сделок.

Для реальных сделок с переменным P&L оптимальное f ищется перебором f от 0,01 до 1:
- HPR_i = 1 + f * (−Сделка_i / Наибольший убыток)
- TWR = произведение всех HPR; среднее геометрическое G = TWR^(1/N)
- Оптимальное f — то, где TWR (и G) максимальны.

Перевод f в размер позиции: f$ = |Наибольший убыток| / f. Пример: наибольший исторический убыток на единицу = 100$, f = 0,25 → 1 единица (контракт, лот) на каждые 400$ баланса. Количество = Баланс / f$. Оптимальное f — это НЕ процент счёта под позицию, а делитель наибольшего проигрыша; риск на сделку в процентах равен f только когда повторится худший убыток.

Для интрадей-трейдера с заранее известным стопом (stop-loss) книга даёт прямую формулу: f$ = Риск по стопу на единицу / f. Пример: стоп = 900$, f = 0,4 → 1 единица на каждые 2250$ счёта. Заранее известный worst case (стоп, опцион) — большое преимущество: устраняет сверхчувствительность f к историческому наибольшему убытку.

Важно: маржа/залог (margin) не имеет никакого отношения к правильному размеру позиции. Также f не зависит от цены инструмента — при изменении цены меняется только f$ (приведение к текущим ценам через процентные P&L).

Для агента: считать f по истории каждой setup-категории; в будущем закладывать убыток хуже исторического (см. просадки), поэтому рабочая доля всегда ниже полного f.
