# Манифест статистик в промптах (CONSTITUTION.md ст. 3 п. 2)

Каждая статистика, попадающая в ЛЮБОЙ промпт любого агента, обязана быть
записана здесь с ответом на вопрос: **«могла ли эта цифра быть порождена
фильтрами самой системы?»** Статистика не из манифеста в промпте = баг ревью.

Формат записи:

| Статистика | Агент | Источник | Могла ли породиться фильтрами системы? | Вердикт |
|---|---|---|---|---|

## Разрешенные

| Статистика | Агент | Источник | Само-порождение? | Вердикт |
|---|---|---|---|---|
| MarketContext (fear_greed, btc_dominance, funding) | Scout, Trader | внешние источники (CMC) | Нет — внешние данные | OK |
| SMC-фичи сетапа (FVG/OB/liquidity, RSI, ATR, тренд) | Scout, Trader | детекторы по рыночным свечам | Нет — рынок, не система | OK |
| Знания из library/ (book_claim) | Scout | книги INVEST ZONE | Нет | OK |
| Календарная информация (время, сессия) | Scout, Sentinel | часы | Нет | OK |

## Запрещенные навсегда (ст. 3 п. 3)

| Статистика | Почему |
|---|---|
| Направление/состав текущего портфеля | Петля v1: «align with portfolio» -> 14/15 SHORT |
| Win-rate по направлениям (LONG WR X% / SHORT WR Y%) | Порождается фильтрами самой системы (блокировки создают статистику, статистика создает блокировки) |
| Формулировки «prefer shorts/longs» в любом виде | Прямой запрет конституции |
| Прошлые вердикты риск-лестницы | Вход вердикта не может содержать производных от прошлых вердиктов |

## Только для Analyst (агент без права торговать)

| Статистика | Условие |
|---|---|
| Полная статистика сделок (WR, PF, по направлениям, калибровка confidence) | Только сырые числа, только Analyst; его выход — Lesson/Proposal, не торговое решение |

## Процедура добавления

Новая статистика в промпт = запись здесь + ответ на вопрос само-порождения +
обычный ревью-коммит. Спорный случай (аудит не дал однозначного «нет») —
статистика НЕ добавляется до разбора в vault/knowledge/decisions/.
