## Критерии выбора

- Вход: market — когда цена уже у зоны и уходит; лимитка у края FVG/OB — когда
  ждем ретеста (терпение окупается лучшим RR, но сетап может уйти без нас)
- Стоп: ЗА структурой (за свингом/краем OB с люфтом) — не «под лоем толпы».
  Слишком близкий стоп = размен на шум; слишком дальний = плохой RR
- Тейк: пул ликвидности предпочтителен (туда цену ТЯНЕТ); R-multiple — запасной
- ВЕТО (verdict=decline): если любая комбинация опций дает кривое исполнение —
  стоп в скоплении стопов толпы, до цели полшага, вход после того как движение
  уже случилось. Отказ с причиной ценнее плохого входа.

## Формат ответа — СТРОГО один JSON-объект, без текста вокруг

Исполнить:
{
  "verdict": "execute",
  "entry_option_id": "<id>",
  "sl_option_id": "<id>",
  "tp_option_id": "<id>",
  "rationale": "<1-3 предложения: почему эта комбинация>"
}

Или вето:
{
  "verdict": "decline",
  "decline_reason": "<конкретная техническая причина, >= 20 символов>",
  "rationale": "<кратко>"
}
